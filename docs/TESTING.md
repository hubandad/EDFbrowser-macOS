# 验证记录

## 当前环境

- Apple Silicon arm64；本机 macOS 27.0.1。
- Apple Swift 6.4 / Command Line Tools。
- 编译最低部署目标 `arm64-apple-macosx14.0`。
- 未安装完整 Xcode，因此 XCTest 框架不可用；通过不依赖 XCTest 的 `EDFCoreCheck` 运行实测。

## 核心检查

`./scripts/check.sh` 运行内建检查。可追加外部 EDF/BDF 路径进行公开样本的读取、往返和参考正弦检查：

```bash
./scripts/check.sh --large \
  /path/to/test_generator_2.edf \
  /path/to/test_generator_2.bdf \
  /path/to/test_generator.edf \
  /path/to/SC4001EC-Hypnogram.edf
```

0.1.0 初始验证结果：**28 项通过，0 项失败**。包含 23 项内建检查、1 项合成大文件检查与 4 个公开外部文件检查。原始通过项列表保存在 `verification-output.txt`。

检查覆盖：

- EDF+ / BDF+ 独立 EDFlib 兼容性、混合采样率、24 位符号扩展、原始数字样本保持。
- 中文/多行/引号标注、亚秒级 TAL、CSV 长宽表往返。
- EDF+D 间隙、截断文件、增长文件不完整记录、非法校准与 UTF-8 拒绝。
- 已知正弦的谱峰、积分 PSD 与方差一致性、三类 IIR 阻带、50 Hz 陷波。
- 抗混叠重采样、FIR 归一化、Parks–McClellan 通带与阻带、aEEG 包络。
- Pan–Tompkins 合成心搏数量及 RR 时序、BioSemi 位触发、Z-ratio 的频率方向。
- 裁剪、选通道、亚秒起点与标注同步、通道校准头编辑、原版 XML 导联执行。
- 缩放抽样保留极值和足够时间分辨率的回归检查。
- PhysioNet `SC4001EC-Hypnogram.edf` 的零秒记录与睡眠事件解析。
- 1 GiB 稀疏 EDF 文件的索引和末尾 1 秒随机读取，在本机本次耗时约 0.024 秒。该文件使用稀疏零页，仅验证地址索引与按需读取路径，不代表真实大文件或多通道完整压力测试。

外部样本来源和许可见 `THIRD_PARTY_NOTICES.md`。样本不包含在交付包中；自带演示由程序生成。

## 0.1.2 单位换算验收

`./scripts/check.sh --large` 本轮结果为 **27 项通过，0 项失败**（26 项内建检查与 1 项大文件检查），见 `verification-0.1.2-output.txt`。新增检查覆盖 μV/mV/V 等幅转换、非电压单位保持、时间/间隙不变、原文件及副本校准保持、PSD 的平方单位关系和积分功率。

实际窗口中打开同一正弦分别以 uV、mV、V 存储的三通道合成 EDF：三者绘图等幅，量程均显示 100 μV。选中 mV 通道后，检查器保留源单位 mV，显示单位及游标幅度为 μV；PSD 图显示 dB μV²/Hz，Delta 功率约 1249.9 μV²（理论值 1250）。方向键量程 100→200→100 μV，“自适应”选项显示明确。

此前的桌面用户样例不在原路径，本轮未重新使用该文件；没有将用户数据加入交付包。

## 0.1.3 播放状态栏回归验收

在用户已打开的官方合成 EDF 样例中复现状态文字随加载指示器出现/消失而左右跳动。保存两条波形的当前显示配置，在独立的修复版实际窗口中重新打开同一文件、载入该配置，验证连续播放、暂停和翻页。

对暂停、两个不同时间点的播放帧、再次暂停及翻页后的状态文字区域进行逐像素比较，结果一致；波形区域在播放过程中正常变化。进度指示器在播放期间持续可见，暂停并完成渲染后隐藏。Release 构建和 arm64 签名校验通过。本轮改动的回归依据是实际窗口验证；先前的数值核心检查记录保持在对应版本章节。

会话与验证截图仅保存在本机临时目录和被忽略的构建目录，没有加入 Git 或发行包。
