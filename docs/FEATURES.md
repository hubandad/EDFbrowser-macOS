# 功能对照与本版范围

基准为 EDFBrowser 2.15 的 [官方功能列表](https://www.teuniz.net/edfbrowser/) 和 [官方手册](https://www.teuniz.net/edfbrowser/EDFbrowser%20manual.html)。用户已确认：原生界面优先、GPLv3、macOS 14+、Apple Silicon、中英双语，以 EEG/睡眠为主，设备专用格式不在本轮范围内。

| 工作流 | 当前实现 | 边界 |
|---|---|---|
| EDF/EDF+/BDF/BDF+ | 原生解析、混合采样率、16/24 位校准、UTF-8 TAL | 读取时校验字段与记录长度；不宣称完整格式认证 |
| EDF+D/BDF+D | 记录时间索引、真实间隙显示、无损副本保存 | 派生连续导出不能跨越间隙，会明确拒绝 |
| 纯标注 EDF+ | 支持零秒数据记录，睡眠图按事件时长展示 | 已使用 PhysioNet Sleep-EDF 文件验证 |
| 波形浏览 | 多文件、绝对/相对同步、时基、增益、独立适应、颜色、反转、滚动；通道勾选与波形名称合并；↑/↓ 调整幅度 | 多文件绝对同步以最早开始时间为原点；编辑文本时方向键不调整幅度 |
| 大文件 | 映射读取、按需读取可见窗口、保留极值的像素抽样；1 GiB 稀疏文件索引/末尾读取已验证 | 未完成真实数 GB/数百通道的压力验收；分析单次原始样本请求上限 400 万 |
| 测量/缩放 | 双游标时间、幅值、Δt、1/Δt、幅值差、拖动缩放、选区 | 屏幕物理标尺需在本显示器校准 |
| 导联 | 单通道、双极、EEG 平均参考、任意导入的线性组合、保存原生导联 | 参与组合的通道需等采样率、兼容物理单位 |
| 原版 `.mtg` | 标签/索引、线性系数、极性、物理尺度、IIR/FIR、低通移动平均、EEG 工频减法 | 不支持导入所有原版特殊处理级；遇到不支持的级会拒绝，不静默遗漏 |
| 会话 | 文件路径、导联、页面、标注、元数据/文件头修改 | 使用原生 `.edfsession`；不导入原版 `.esf` |
| 标注 | 搜索、定位、增删改、持续时长、中文、撤销重做、CSV | 保存为新副本，不覆盖源文件 |
| 睡眠分期 | W/N1/N2/N3/REM/未评分、20/30 秒 epoch、自动前进、可隐藏/恢复并记忆显示状态的睡眠图 | 不含自动睡眠分期模型 |
| IIR/工频 | 1–8 阶 Butterworth/Chebyshev/Bessel、高/低/带通组合、可调 Q 陷波、EEG 工频减法 | 因果滤波；浏览时按截止频率预热；起点/间隙后有滤波暂态 |
| 移动平均/尖峰 | 原版高/低通移动平均与尖峰抑制核心 | 原版尖峰算法要求 4–128 kHz，不适用于常见低采样率 EEG |
| FIR | Hamming 窗 sinc、Parks–McClellan、自定义系数 | 最多 4095 个 taps；因果群延迟不自动抵消 |
| 频谱/CDSA | Welch PSD、Hann/Hamming/Blackman/矩形窗、50% 重叠、频带积分、CSV | 可选 FFT 长度；跨记录间隙的 PSD 选区会拒绝 |
| aEEG/CFM | 2–15 Hz 八阶带通→整流→0.5 Hz 四阶低通→分段包络 | 输出线性 µV 包络；尚未复刻原版全部显示模式 |
| Z-EEG | 2 秒 FFT、可调交叉频率、Z-ratio 时间序列 | 使用 0.5–25 Hz 的低/高频相对功率定义 |
| 事件平均 | 事件触发、前/后窗口、基线校正、边界/间隙拒绝、CSV | 未实现原版所有触发策略与叠加显示模式 |
| QRS/RR/HRV | 原版 Pan–Tompkins 核心、心率曲线、RR、SDNN/RMSSD/pNN50、心搏标注 | ≥200 Hz；未做异位搏动校正；长记录按带预读的块处理 |
| 统计 | 信号均值、SD、RMS、极值、峰峰值、各睡眠阶段时长 | 手工重叠的分期事件可能重复累计，需人工避免重叠 |
| EDF/BDF 导出 | 选通道、裁剪、滤波/导联、16/24 位、抗混叠 sinc 重采样 | 整数输出 Hz；尾记录补齐并标注；范围超限拒绝而不静默裁剪 |
| CSV | 宽/长表导入、原始物理样本长表导出、事件/分析 CSV | 导入要求均匀整数 Hz、等长信号；不支持任意设备专用文本布局 |
| 文件头 | 标识、去除患者标识、记录日期、标签、单位、缩放、传感器、预滤波描述 | 暂存后保存副本；不是原版全部容错修复算法的移植 |
| 合并 | 通道叠加与按时间拼接，保留来源边界标注 | 需连续记录、兼容采样率；时间拼接要求相同通道布局 |
| 视频 | AVFoundation 播放，记录时间驱动，手动偏移 | 系统支持的编解码；未实现全部 VLC 格式和文件名自动同步 |
| 增长文件 | 读取完整新记录、追踪尾部、保留已有编辑 | 需要实际采集设备的长时间验收 |
| BioSemi | BDF Status 通道低 16 位触发事件解析 | 按非零代码变化生成事件 |
| 打印/图像 | 原生波形 PDF 与 PNG 导出 | 当前绘制的波形视图；分页打印排版未扩展 |
| 远程控制 | 默认关闭、本地 TCP、JSON 响应、导航命令 | 独立 Mac 协议，不兼容原版全部远程控制指令 |
| 设备转换器 | 不实现 | 用户明确确认 EDF/BDF 和 CSV 即可 |

本版提供了主要 EEG/睡眠工作流，但不能宣称已与 Windows 2.15 的每一个命令、参数和文件格式完全等价。当前交付用于实际试用与后续验收；版本差异在此表中明确列出。
