# 功能优化检查（0.1.4）

本轮围绕 EEG/睡眠阅览的日常流程检查代码，并通过合成 EDF、自动检查和实际 macOS 窗口验证。它不替代所有设备数据、系统版本和多小时高通道压力验收。

## 已落实

| 发现 | 影响 | 0.1.4 处理 |
|---|---|---|
| 图标由通用折线和网格组成，小尺寸识别与品牌特征不足 | Dock 与 Finder 辨识度 | 新的 E/EEG 图标、透明边缘、完整 Retina 尺寸 |
| 会话遗漏自动量程、游标、搜索及分期偏好 | 重开后需要重复配置，测量上下文丢失 | 补齐可选字段，保持旧文件兼容；验证实际保存恢复 |
| 载入另一会话会替换未保存的修改 | 标注修改可能意外丢失 | 增加取消、保存当前会话、放弃后打开的明确选项 |
| 播放末尾的计时器继续运行，且固定按 0.1 秒推进 | 末尾仍显示播放；计时延迟后速度不准 | 单调时钟、末页自动停止、再次播放从头开始 |
| 取消外层任务并未取消独立后台计算 | 快速导航时仍处理过时窗口 | 将取消传播到后台任务及读取/滤波检查点 |
| 游标读数依赖绘图包络中的最近点 | 缩小时可能缺少实际游标样本 | 独立读取实际物理样本并按当前处理链计算 |
| SwiftPM 声明了不存在的目标资源目录 | 源码构建产生无效资源警告 | 删除多余声明，沿用明确的资源打包路径 |

## 建议后续优先项

| 优先级 | 方向 | 验收建议 |
|---|---|---|
| 高 | 长记录、高通道与滤波绘图性能 | 使用真实整夜 64/128 通道数据建立帧耗时和内存基线，再评估滤波后像素包络及窗口缓存 |
| 中 | 全记录分析的取消与进度 | 给 CDSA/事件平均等长分析增加明确的取消按钮和分段进度，验证关闭面板后停止计算 |
| 中 | 会话文件移动后的重定位 | 找不到 EDF/BDF 路径时提供重新选择文件并校验通道结构的流程，减少换机器/移动目录的阻碍 |

本轮没有引入新的设备格式、自动睡眠判读或分析算法；具体已实现范围仍以 [功能对照](FEATURES.md) 为准。
