# 0.1.2 更新

- 电压波形统一使用 μV 显示；对 mV 和 V 源数据进行实际数值换算。非电压通道保留原单位。
- 工具栏原“100/行”更名为“量程 100 μV”。默认增益下代表总垂直范围 100 μV，即零线上下各 50 μV；量程越小，波形越大。每条波形下方标明考虑单独增益、自动适应或导联校准后的实际量程。
- 游标幅度、事件平均、信号统计、功率谱及 CDSA 同步使用显示单位；电压功率谱使用 μV²/Hz，频带功率使用 μV²。
- 检查器同时显示源单位与显示单位。EDF/BDF 源文件、物理校准及记录导出保留原始单位和数据。

## 验证

新增三项检查：电压单位及非电压单位转换；三种源单位的等幅波形和无损副本；PSD 的平方单位换算及积分功率。与既有核心检查和 1 GiB 稀疏文件检查合计 **27 项通过，0 项失败**。

通过合成的三通道对照文件实测界面：各通道分别以 uV、mV、V 存储同一条峰值 50 μV 正弦波，实际绘图等幅。mV 源通道的游标显示 μV；功率谱显示 dB μV²/Hz，1 Hz 正弦的 Delta 频带功率约 1249.9 μV²，与理论值 1250 μV² 一致。量程菜单包含单位和“自适应”，方向键可使量程 100→200→100 μV。测试数据不包含用户记录。
