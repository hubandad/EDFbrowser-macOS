# 0.1.3 更新

修复播放波形时左下角“已打开记录”状态文字闪烁、左右跳动的问题。

原因是每次波形渲染开始和结束时，状态文字前面的进度指示器被插入、移除，从而反复改变文字位置。现在为指示器保留固定宽度的位置，并在连续播放期间保持指示器可见；暂停或渲染完成后隐藏指示器时，文字布局仍保持稳定。

## 验证

在已打开的官方合成 EDF 样例上复现旧版问题，保存当前两通道配置后，在 0.1.3 实际窗口中重新载入相同配置，验证连续播放、暂停和翻页。

逐像素比较暂停前、不同时间点的两个播放帧、再次暂停和翻页后的状态文字区域，结果一致；波形绘图区同时正常更新。播放时进度指示器持续显示，暂停并完成渲染后隐藏。完成 arm64 Release 构建与代码签名校验。
