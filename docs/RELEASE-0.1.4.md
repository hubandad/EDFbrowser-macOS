# 0.1.4 更新

- 全新 macOS 图标：用平滑 EEG 波形构成抽象字母 E，使用深蓝底板和珍珠白/青绿层次，提供完整的 16–1024 px 图标尺寸。原始素材及提示词见 [图标设计](ICON-DESIGN.md)。
- 会话保存自动量程、检查器显示、双游标、选区、通道搜索、当前文件/通道和睡眠分期偏好，兼容旧会话。打开另一会话时，增加未保存修改的保护选项。
- 播放根据实际经过时间推进，到最后一页自动停止；在末尾再次播放会从头开始。关闭最后一个记录时停止后台播放和渲染。
- 快速导航会取消过时的后台渲染，并在读取、包络、导联和滤波处理中响应取消，减少无效计算。
- 游标幅值异步读取实际样本，遵循当前导联、滤波和 μV 换算，避免以缩小后的绘图抽样点作为测量值；记录间隙中不显示虚构样本。
- 清除 SwiftPM 中无效的资源目录声明；应用资源统一由打包脚本复制。

## 验证

`./scripts/check.sh --large`：**35 项通过，0 项失败**。新增覆盖新/旧会话、非法状态、延迟计时、播放边界、精确游标、EDF+D 间隙和取消长 FIR 任务。旧有读取、写入、滤波、PSD、单位换算和 1 GiB 索引检查全部通过。

实际 macOS 窗口验证：新会话显示状态、旧会话兼容、保存后恢复、未保存标注时取消打开另一会话、到末尾停止及从头重播、关于窗口的新图标与版本。独立解析合成 EDF 的两个游标样本得到 −94.072 μV 和 −56.168 μV，与界面一致。会话恢复还保留了本轮新增的测试分期事件。

ICNS 经系统工具反向解包，确认含全部十个标准表示，像素尺寸覆盖 16、32、64、128、256、512、1024；PNG 为透明 RGBA。arm64 Release 构建通过，实际窗口运行于 macOS 27.2，部署目标为 macOS 14。其他系统版本的实机验证仍见测试说明。

用户记录、会话及调试截图不包含在发行包中。
